# Archita's Portfolio

Welcome to my personal portfolio website! This project showcases my work, skills, and background as a developer.

## Live site

[Visit the portfolio](https://my-portfolio-nu-two-88.vercel.app/)

## Tech stack

- React 18
- Create React App (`react-scripts`)
- CSS and Bootstrap
- Deployment: Vercel

## Run locally

```bash
git clone https://github.com/architaa1/My_Portfolio.git
cd My_Portfolio
npm ci
npm start
```

The development server runs at http://localhost:3000.

## Build

```bash
npm run build
```

Create React App writes the production site to `build/`. The Vercel configuration in `vercel.json` sets the build command, install command, and output directory explicitly. Connect this repository to Vercel and deploy from the `main` branch; subsequent pushes will trigger deployments.

## Features

- Responsive portfolio with About, Education, Skills, Projects, Work Experience, and Contact sections
- Theme support
- Contact form and interactive navigation
